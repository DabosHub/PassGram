# Changelog

PassGram uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The packages currently say `0.1.0` because that is the working version. No Git tag has been cut.

## Unreleased

The source on `main` is the work leading to the first public release. A `v0.1.0` tag will be created when that release is announced, and this file will name what that tag contains. Until then, `git log` on `main` is the history.
